## 3. Assignment Tasks

### Task 1 – Evaluate the Requirements of Each Computing Environment
Analysis of response time, reliability, throughput, battery and security requirements for different hospital computing environments.

### Task 2 – Judge the Type of Operating System for Each Environment
Comparison and selection of suitable operating system types for patient monitors, tablets, workstations, database servers, imaging servers and partner hospital networks.

### Task 3 – Evaluate Operating-System Structures
Comparison of monolithic, layered, microkernel, modular and hybrid operating-system structures.

### Task 4 – Evaluate the Services an Operating System Must Provide
Analysis of operating-system services such as process execution, I/O operations, file systems, communication, resource allocation, protection and security.

### Task 5 – Examine System Calls
Study of system call categories, execution of read() and analysis using strace.

### Task 6 – Evaluate the Cost of System Calls
Implementation of a file-copy program using read() and write() system calls and comparison of different buffer sizes.

### Task 7 – Evaluate Process Control System Calls
Implementation and analysis of fork(), execlp(), waitpid() and process exit status.

### Task 8 – Evaluate CPU States and Protection
Analysis of user mode, kernel mode, interrupts, traps and memory protection.

### Task 9 – Evaluate the Memory Hierarchy and I/O Systems
Study of registers, cache, main memory, SSD, hard disk, network storage, programmed I/O, interrupt-driven I/O and DMA.

### Task 10 – Measure and Compare
Measurement and comparison of system calls, execution time, process creation and thread creation.

### Task 11 – Recommend and Defend the Operating-System Plan
Design and recommendation of a complete operating-system plan for the smart hospital.

### Task 12 – Re-evaluate and Adapt the Design
Modification of the hospital operating-system design to support remote patient monitoring and cloud-based records.
